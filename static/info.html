Privacy

All requests to this site are permanently logged according to this NGINX log format:

log_format main '[$time_local] REQUEST: $remote_user@$remote_addr $body_bytes_sent "$request" agent:"$http_user_agent" refer:"$http_referer" to host "$http_host" - RESPONSE: $status';

So the following information about each request is logged:
  • IP address
  • User (your username, when requesting anything under /user)
  • Request
  • User Agent
  • Referer
  • Host

This data is used exclusively for troubleshooting and gathering statistics locally. Log data is never disclosed or shared with any individuals or entities, and is strictly accessible to server-gateway system administrators. As of 2026-10-18, the current server-gateway sysadmins are:

  • nixwiz (https://nixwiz.network)
  • stilic (https://kitty.tel/~stilic/)

Given the above Hosting section, the following entities technically have the ability to monitor the frequency, timing, and source of any requests to The Tunnel Archive, but not any request data:

  • RackNerd LLC
  • Verizon Communications Inc.
