Frequently Asked Questions

Run in >2020? But isn't Flash dead?

Adobe Flash reached its end of life in 2021. The installments in the Run Series, primarily, are Flash games. While the Flash EOL cripples the ability to run Flash content through a browser, the ability to run Flash content through the Adobe Flash Player Projector is not affected. A guide on how to play the Run Series after the Flash EOL can be found here - but if you want to publish levels made in Run 3, please read a bit further.


What's the difference between a "level" and a "tunnel"?

"Tunnels" were introduced in Run 3. They are a gameplay mechanic that splits the game's levels into separate playable segments, consisting of "levels". For example, Run 3's "Plan A" is an example of a tunnel, whereas Plan A, part 16 is an example of a level.


So, how do I start creating?

All installments in the Run series come with a built-in level editor. The first two games let you export your level's data by copying it, while the third does not. To circumvent this issue, the Run 3 Import/Export Mod was created, which puts a textbox in the level editor for importing or exporting level data. Additinally, this mod adds new features and tile types, so Run 3 levels created with the Import/Export mod are not compatible with base Run 3, and must be correctly labeled in the "Game" dropdown when uploaded. Levels created in base Run 3 can be played with the Import/Export mod, however.

Once you're done making your level, you can upload it to The Tunnel Archive here. If you want to create a tunnel, do so by going here and listing each level's level ID (shown on it's page), separated by new lines.


I need help, where do I go?

If you're having issues or need clarification on anything, please feel free to join the Run Planet community Discord server. Once you're verified, you can ask in either the #run-general or #run-mods channel, and we'll try our best to help you. If you have a bug or feature request for the site, please ping me (@wwp0s0 in the server) along with it in one of those channels so I can see it as quickly as possible.
